# Present Of Krypton

![Present Of Krypton](https://jorelmagatti.github.io/PresentOfKrypton/web/icon192.png)

Welcome to Present Of Krypton, an exciting game developed using the GDevelop platform! Dive into a thrilling adventure inspired by the mysteries of Krypton. This game is a reimagination of Superman's origin story, where he is launched by his father to Earth. Designed as a unique mini-game for a gender reveal, it culminates in revealing whether your first child is a boy or girl, along with their name. The game is available to play online and can be downloaded for Windows, Linux, and Android.

## About the Game
Present Of Krypton is a reimagination of Superman's journey, beginning with his launch from Krypton by his father to Earth. This innovative mini-game serves as a gender reveal experience, guiding players through an engaging adventure that ends with the exciting revelation of whether your first child is a boy or girl, along with their name. Built with GDevelop, it offers a fun and memorable way to share this special moment.

## Installation Instructions
### Windows
1. Download the `.zip` file from the link above.
2. Extract the contents to a folder on your computer.
3. Run the executable file (e.g., `PresentOfKrypton.exe`) to start the game.

### Linux
1. Download the `.AppImage` file from the link above.
2. Make the file executable: `chmod +x PresentOfKrypton.AppImage`
3. Run the file: `./PresentOfKrypton.AppImage`

### Android
1. Download the `.apk` file from the link above.
2. On your Android device, enable "Install from Unknown Sources" in settings.
3. Open the `.apk` file and follow the prompts to install.
4. Launch the game from your app drawer.
